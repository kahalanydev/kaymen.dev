    Case studies

    Every one includes the part that broke

    A capability list is free to write. Naming what went wrong is not.

    Platforms

    Four campuses, one database, isolation that had to be provably real

    One WordPress install per campus, the same student existing three times with three histories. Replaced with a single multi-tenant platform, migrated while the old one stayed live.

    The hard part

    Row-level security that silently did nothing. The database user had been provisioned as the cluster's bootstrap superuser — and superusers bypass RLS unconditionally. The policies were in place. The tests passed. The isolation layer was inert.

    In production2026
    Platforms

    A $1.58M fund whose headline number was wrong by $47,383

    An interest-free community loan fund on spreadsheets, with contracts in Drive and a bookkeeping tool that cannot export a transaction.

    The hard part

    Fund size was computed from money in, so it could only ever rise. Four years of fees and write-offs never came off. The fix changed what the system claims to measure — a decision to take with the client, not a patch to ship quietly.

    In production2026
    Integrations

    Billable hours were leaking, and the API could not answer the question

    An MSP could not tell whether its engineers were logging time. At 243,000 lifetime tickets, any query broad enough to be useful times out and returns nothing at all.

    The hard part

    Bounded backfill plus continuous delta sync, with per-entity sync state so an interrupted run resumes rather than restarts. When an API cannot answer your question, you now own a synchronisation problem.

    In production2026
    Apps

    The booking calendar rendered perfectly, and it was empty

    A bilingual Hebrew/English booking platform replacing phone-and-WhatsApp scheduling, with an admin a non-technical owner actually uses.

    The hard part

    A failure mode with no error state. The site was up, the API returned 200, the calendar rendered — and had nothing in it. No monitor you would think to set up can tell that apart from a quiet week.
